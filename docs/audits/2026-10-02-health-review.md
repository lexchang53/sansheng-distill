# 蒸馏 Skill 结构体检与修复报告

日期：2026-10-02（北京时间）  
对象：sansheng-distill 独立仓；基线 87a2b85。优先级：效率优先，保留来源忠实、核心完整与实际消费者验收。

## 1. 结论

问题主要在编排和规则边界：入口按书页讲流程，人物专题缺位，书籍档位和审阅层叠加，历史项目参数升级为通用默认，局部资料交付被扩大成全人物/整站工程。另发现会产生假成功的机器路径。已修路由、默认、披露、参考冲突及相关脚本，保留既有 schema 与科学验收。

入口从 17,594 字节减至 7,178 字节，减少 59.2%。这是默认加载体积变化，不是实测总 token 或生产耗时。参考长文仍保留专业细则，按对象和当前阶段定位读取。

## 2. 体检范围与方法

盘点入口、全部参考/模板/脚本及测试布局（当前 25 份 Markdown 参考、29 个顶层 Python 脚本），核独立 Git 身份与真实调用者。重点沿书籍定档、人物思想/生平、主题聚合、视频来源、深读校验→导出的风险链阅读；不是声称每个历史工具都重新审过全部实现。另做独立只读审计、10 类真实意图的前向路由试跑、机器检查与失败变异。

与企业研究、一页课桌、网站工程核分工。本 Skill 不拥有企业财务/控制权研究或正式站发布链；企业蒸馏应由 sandy-firms 主导，其中书籍/人物子任务返回本 Skill。

## 4. 脚本修复

- verify_deepread：无真实 Markdown 稿件返回失败；忽略非稿件/目录；空来源料包也失败。
- export_deepread：清单非空、ID 唯一、类型合法；按清单 ID 调真实 checker；异常退出或红项在写包前阻断，不再只搜 stdout 判断成功。
- build_series：空、纯标点、无正文字幕不当作可用转写；乱码率只算正文，每集独立核 2% 既有阈值，不被长篇正常集稀释；失败保留诊断，不写新语料。
- 部分缺集仍保留现有 exit 0 接口与明确缺口诊断；执行规则要求补齐或声明节选，不冒称全系列完成。

现有脚本在任务开始前有执行权限变更；本轮只提交内容修复，保留其工作区权限状态和其他暂存文件，不卷入他人改动。
