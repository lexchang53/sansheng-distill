# 人物专题：先限定范围，再选择证据路线

适用：某人的某个思想、问题、阶段或事件。专题是范围，不是新数据 schema；复用创作者或传记的相关证据，避免启动全人物工程。

## 1. 识别与范围

| 目标 | 复用的路线 | 首读小节 |
|---|---|---|
| “王阳明的教育思想”“某博主的定价方法” | creator 的来源卡、观点归并、归属与外部核验 | creator-craft.md §2、§3.2、§6 |
| “王阳明龙场时期的经历”“某人某事件中的关系” | biography 的观察、异说与事实裁决 | biography-craft.md §0、§1；入库才读 §2–§8 |
| 主题同时涉及思想与事件 | 两种来源各自记录并建立引用 | 不把本人自述当外部事实证据，不把事实年表当思想体系 |
| “只蒸这段视频/这本书中的相关部分” | 作品路线的明确节选 | 声明来源范围，不扩为全人物 |
| “从已蒸两本书里比较他的教育思想” | 已有作者资料或专题整理 | 不重新采集原书；正式作者页沿 StepA，正式跨书主题页沿 StepB |

确定问题、年代（若有）、纳入/排除的来源、已有成果和本轮终点。没指定时间就不强加时间窗；先复用相关来源，需要补源才定向检索。若来源中关键反证落在范围外，说明并补读必要上下文，不据节选断言全人生或全部思想。

## 2. 最小生产流程

1. 盘点与主题相关的现有来源、观点或事实，记录版本及页/段/时间码；只补关键缺口。
2. 从真实来源提取观点、关键案例、条件、反例、异说及演变；跨源重复归并，独有细节保留来源。索引有该人物不等于相关证据已存在。
3. 围绕专题写一套连续可读的正文；一轮检查来源忠实与重要遗漏，回源裁决报警和高风险内容，定点修改与复验。科学、高后果和重大史实冲突沿其专项核验，不因限定范围免核。
4. 输出专题资料、问题地图与来源/缺口；有现成项目契约则按其格式交付。只交资料时，不强制为全人物每个条目配长文或生成整站数据。

思想专题不宣称覆盖全部作品；生平专题不报全传完成或全生涯保留比例。creator 全量项目的数量/密度/篇幅指标仅用于其声明的完整读物，不能机械套到专题。

## 3. 入库与消费者

- 新建公开人物资料库时仍使用对应已注册的身份、namespace、schema 与审计；专题范围可以收窄，必填字段不能伪造。
- 现有库局部更新，只改本专题真实证据及受影响投影，复用未变审据。biography 正式裁决仍由授权 reviewer 签署，外部模型只给建议。
- 只有网站终点才加载 creator 的展示/工程条款或下游产品要求。消费者要求完整人物包时，限定专题不能硬填空值冒充全量；改交明确范围的资料，或实现消费者明确支持的专题适配并验证。
- 一份完整全量语料中的专题视图只是筛选投影，不复制事实层或重新蒸馏。先复用 Canonical/观点族，再补缺失主题。
